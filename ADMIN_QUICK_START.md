## 🐛 Quick Troubleshooting

**Can't access admin?**
1. Go to http://localhost:8081/admin/login
2. Use the credentials above
3. Check browser console for errors

**Stats not showing?**
- Make sure there's data in database
- Try creating a test booking from homepage

**Page not loading?**
- Restart server: Stop (Ctrl+C) then `npm run dev`
- Clear browser cache
- Try incognito mode
