## 🐛 TROUBLESHOOTING

### Can't Access Admin?
**Problem:** Page not loading  
**Solution:** 
1. Check server is running: See terminal
2. Verify URL: http://localhost:8081/admin/login
3. Clear browser cache
4. Try incognito mode

### Can't Login?
**Problem:** Invalid credentials  
**Solution:**
1. Check email: sureshkubarudri@gmail.com
2. Check password: Admin123!@#password
3. Check browser console for errors
4. Verify Supabase connection

### Statistics Not Showing?
**Problem:** Dashboard shows 0  
**Solution:**
1. Check if there's data in database
2. Create test bookings from homepage
3. Check browser console for errors
4. Verify database connection

### Bookings Not Loading?
**Problem:** Empty bookings list  
**Solution:**
1. Check if appointments exist in database
2. Try removing filters
3. Check browser console
4. Refresh the page
