┌──────────────────────────────────────────────────────────────────────┐
│  HOW PUBLISH/UNPUBLISH WORKS                                         │
└──────────────────────────────────────────────────────────────────────┘

   WORKFLOW:

   Step 1: Upload Image
   ─────────────────────
   [Admin Panel] → Click "Add New Image" → Upload photo
                ↓
   ✅ Image uploaded to admin gallery
   ✅ Status: PUBLISHED (by default)
   ✅ Visible on website immediately


   Step 2: Unpublish Image (Hide from Website)
   ─────────────────────────────────────────────
   [Admin Panel] → Find image → Click "Unpublish from Website"
                ↓
   ✅ Badge changes: Green → Gray
   ✅ Button changes: "Unpublish" → "Publish"
   ✅ Image hidden from website
   ❌ Customers can't see it
   ✅ Still in admin panel


   Step 3: Publish Image (Show on Website)
   ────────────────────────────────────────
   [Admin Panel] → Find image → Click "Publish to Website"
                ↓
   ✅ Badge changes: Gray → Green
   ✅ Button changes: "Publish" → "Unpublish"
   ✅ Image visible on website
   ✅ Customers can see it

┌──────────────────────────────────────────────────────────────────────┐
│  WHAT HAPPENS ON WEBSITE                                             │
└──────────────────────────────────────────────────────────────────────┘

   PUBLIC WEBSITE PORTFOLIO:
   URL: https://www.lakshanaatelier.in (scroll to Portfolio)

   ✅ Shows ONLY images with "Published" status
   ❌ Hides ALL images with "Unpublished" status
   🔄 Updates automatically (no page refresh needed)


   EXAMPLE:

   You have 10 images in Admin Gallery:
      • 6 images = Published (Green badge)
      • 4 images = Unpublished (Gray badge)

   Website Portfolio shows:
      • 6 images (only the published ones)
      • 4 images are invisible to customers
